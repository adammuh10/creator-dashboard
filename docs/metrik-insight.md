# Metrik insight yang ditampilkan

Daftar metrik dari Instagram, TikTok, dan YouTube, dan di halaman mana
masing-masing muncul. Data masuk lewat file ekspor atau screenshot, jadi
metrik yang tidak ada di file pengguna akan tampil "–".

## Instagram

| Metrik di Instagram | Di aplikasi |
|---|---|
| Views, jangkauan (accounts reached) | Ringkasan, Postingan |
| Interaksi: suka, komentar, bagikan, simpan | Postingan (tabel dan detail) |
| Engagement rate | Ringkasan, Postingan |
| Views dari followers vs bukan followers | Postingan (detail), Audiens |
| Sumber views: tab Reels, Beranda, Explore, Profil, Hashtag | Postingan (sumber penonton) |
| Rata-rata waktu tonton Reels | Postingan |
| Aktivitas profil: kunjungan profil, klik link, follow | Ringkasan (aktivitas profil), Postingan |
| Followers: total, follow, unfollow | Audiens |
| Story: views, jangkauan, maju, kembali, keluar, story berikutnya, balasan, klik link, tap stiker | Postingan → Instagram → Story |
| Demografi: umur, gender, kota, negara | Audiens |
| Waktu paling aktif followers (hari × jam) | Audiens |

## Dihitung oleh aplikasi

| Metrik | Cara hitung |
|---|---|
| Jam terbaik posting | Rata-rata views per hari × blok 3 jam, dari postingan 90 hari |
| Konsistensi posting | Minggu yang mencapai target post ÷ jumlah minggu |
| Saran minggu ini | Aturan yang membandingkan waktu, durasi, hook, topik, format, jangkauan ke non-followers, audiens, konsistensi, CTR YouTube, dan Story. Setiap saran menyertakan angka buktinya |
