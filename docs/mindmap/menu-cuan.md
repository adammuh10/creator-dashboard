# Menu Cuan

## 1. Kerja sama (brand deals)

- Kolom seperti Notion-mu
  - Brand
  - Status konten
  - Tgl post
  - Status bayar
  - Tgl bayar
  - Fee
  - Akun (@tipscareer, @tipsngonten)
  - SOW
- Rapikan "Platfrom"
  - Platform: IG, TikTok, YouTube
  - Format: Reels, Carousel, Story, Video
  - Add-on: Collab, Mirroring, Owning, Link
- Lewat perantara
  - Nama manager / agensi
  - Komisi %
  - Fee bersih
- Termin
  - DP
  - Pelunasan
- Status konten
  - Nego → Deal → Draft → Revisi → Approved → Posted
- Status bayar
  - Belum → Ditagih → DP → Lunas
  - Telat
- Link bukti tayang + insight
- Brief dan kontrak (file / link)
- SOW → tugas otomatis di menu Tugas

## 2. Profil penagih (isi sekali)

- Nama sesuai KTP / rekening
- Alamat
- No HP / WA
- Email
- NIK
- NPWP (16 digit, sama dengan NIK)
- Status PKP
- Rekening
  - Bank
  - No rekening
  - Atas nama
  - Bisa lebih dari satu
- Tanda tangan
  - Gambar langsung
  - Upload PNG
- Logo (opsional)
- Format nomor invoice

## 3. Invoice

- Dibuat dari baris kerja sama
- Nomor otomatis, bisa diedit
- Tanggal dan jatuh tempo
- Bill to
  - Nama PT / brand
  - Alamat
  - PIC dan email
  - No PO (kalau diminta)
- Tabel item
  - Deskripsi (dari SOW)
  - Qty
  - Harga satuan
  - Jumlah
- Subtotal
- Diskon
- PPN (kalau PKP)
- Potongan pajak (lihat Pajak)
- DP yang sudah dibayar
- Total tagihan
- Total bersih diterima
- Terbilang
- Rekening tujuan
- Tanda tangan + nama
- Pengingat meterai (di atas Rp5 jt)
- Catatan / syarat bayar

## 4. Kirim dan lacak

- Unduh PDF
- Link invoice
- Kirim lewat email / WA
- Status: Draft, Terkirim, Lunas, Telat, Batal
- Pengingat jatuh tempo
- Template pesan follow-up
- Kwitansi otomatis saat lunas

## 5. Arsip

- Semua invoice dan kwitansi tersimpan
- Cari dan filter
  - Brand, akun, tahun, status
- Unduh ulang PDF
- Duplikat invoice
- Terkunci setelah terkirim
  - Ubah = revisi baru
- Ekspor CSV / Excel untuk akuntan

## 6. Rate card

- Data dasar
  - Median views 30-90 hari (dari impor)
  - Engagement rate
  - Followers
- Rumus
  - Views ÷ 1.000 × tarif per 1.000 views
  - × faktor engagement
  - × faktor format
  - \+ add-on
  - − diskon paket
  - dibulatkan ke Rp50.000
- Tarif per 1.000 views
  - Isi sendiri
  - Atau dihitung dari fee deal lama
- Add-on
  - Collab post
  - Link in bio / IGS tap link
  - Mirroring ke platform lain
  - Owning / hak pakai per bulan
  - Eksklusif kategori
  - Ads / Spark code
  - Kirim cepat (rush)
  - Raw footage
  - Revisi tambahan
- Hasil
  - Harga buka (untuk nego)
  - Harga minimum
- Harga custom
  - Harga rumus (otomatis)
  - Harga kamu (dikunci)
  - Harga di rate card (setelah aman pajak)
  - Peringatan kalau terlalu murah
- Paket custom
  - Nama + isi bebas
  - Harga otomatis − diskon
  - Atau harga tetap
  - Tampil "hemat Rp…"
- Riwayat versi rate card
- Template
  - Per akun
  - Paket: single, bundle, bulanan
  - Syarat: DP, revisi, hak pakai
- Bandingkan dengan fee asli
- Bagikan: PDF / link

## 7. Pajak

- Pilihan potongan per invoice
  - Tanpa potongan
  - PPh 21 dipotong brand
  - PPh 21, harga aman pajak
  - PPh 23 2% (PT/CV)
- Tarif PPh 21
  - 2,5% (default)
  - 3% (tanpa NPWP)
  - Isi sendiri
- Harga aman pajak
  - Ditagih = bersih ÷ (1 − tarif − komisi)
  - Dibulatkan ke atas
  - Kamu terima ≥ rate-mu
- Tampilan invoice
  - Ringkas: tanpa baris pajak
  - Rinci: nilai jasa, PPh, ditransfer
- Perkiraan uang bersih per deal
- Simpan bukti potong
- Rekap tahunan untuk SPT
- PPN kalau sudah PKP

## 12. Gratis vs Pro

- Gratis
  - Kerja sama tanpa batas
  - 3 invoice / bulan
- Pro
  - Invoice tanpa batas
  - Kwitansi, pengingat, link invoice
  - Rate card otomatis
  - Rekap pajak dan ekspor
  - Impor Notion
