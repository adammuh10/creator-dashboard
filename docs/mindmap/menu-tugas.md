# Menu Tugas: prep konten

## 1. Tujuan

- Jawab "hari ini aku harus ngapain?"
- Ide → terbit → evaluasi dalam satu alur
- Bisa dipakai sambil syuting, satu tangan
- Tidak mulai dari nol: template dan AI
- Jaga ritme, cegah burnout

## 2. Tampilan

- Hari ini (default di HP)
  - Terlambat
  - Hari ini
  - Besok
- Papan per tahap (kanban)
- Kalender minggu / bulan
- Daftar + filter
  - Brand, platform, tahap
  - Prioritas, jenis konten
- Detail konten
  - Semua tugas dan checklist-nya
- Mode syuting
  - Shot list layar penuh
  - Teleprompter
  - Layar tetap menyala
- Hari batch
  - Kelompokkan rekaman per lokasi / outfit

## 3. Tahapan produksi

- Mode simpel: Rencana → Rekam → Edit → Terbit
- Mode lengkap: 9 tahap
- Ide & riset
  - Pilih dari Bank ide
  - Simpan video referensi
  - Tujuan: awareness, engagement, jualan, endorse
  - Pilar konten dan audiens
  - Cek tren, sound, kompetitor
- Brief
  - Format: video pendek, carousel, foto, live, long-form, story
  - Platform utama + turunannya
  - Angle dan pesan utama
  - 3 opsi hook
  - CTA
  - Durasi target
  - Tanggal dan jam posting (dari data jam terbaik)
- Naskah
  - Template hook → isi → CTA
  - Poin-poin atau naskah penuh
  - Draft caption
  - AI: varian hook, rapikan naskah
  - Approval brand (endorse)
- Pra-produksi
  - Shot list A-roll dan B-roll
  - Lokasi dan cahaya
  - Produk dan properti
  - Outfit dan makeup
  - Alat: HP, mic, lampu, tripod, baterai, memori
  - Kolaborator / talent
  - Cuaca (kalau outdoor)
- Rekam
  - Centang shot yang sudah diambil
  - Catat take terbaik, retake
  - Foto untuk cover
  - Backup file ke Drive
- Edit
  - Pilih take
  - Potong, subtitle, teks hook 3 detik pertama
  - Musik / sound aman hak cipta
  - Cover / thumbnail
  - Versi per platform: rasio dan durasi
  - QC: audio, typo, logo brand, label iklan
- Terbit
  - Caption, hashtag, tag brand, lokasi
  - Link affiliate / keranjang
  - Jadwalkan, atau pengingat posting manual
  - Pin komentar pertama
  - Tempel link postingan → status Terbit
- Setelah terbit
  - Balas komentar di jam pertama
  - Share ke story, WA, grup
  - Kirim bukti tayang ke brand
  - Boost / iklan (opsional)
- Evaluasi
  - Cek 24 jam dan 7 hari
  - Bandingkan dengan target dan rata-rata
  - Catat pelajaran
  - "Buat lagi" → Bank ide
  - Tagih pembayaran → Cuan

## 4. Template per jenis konten

- Video pendek (TikTok, Reels, Shorts)
- Carousel Instagram
- Foto feed
- Story harian (berulang)
- Live jualan
- YouTube panjang
- Konten affiliate
- Konten endorse
- Kolaborasi
- Konten berseri (Part 1, 2, 3)
- Template buatan sendiri

## 5. Alur endorse

- Brief masuk, catat deliverable
- Deal: rate, jumlah revisi, deadline, hak pakai
- Tunggu produk datang
- Draft naskah → approval brand
- Draft video → revisi
- Posting + label "kolaborasi berbayar"
- Bukti tayang + insight (H+1, H+7)
- Invoice → dibayar (Cuan)

## 6. Isi satu tugas

- Judul
- Konten induk (atau tugas lepas)
- Tahap
- Jatuh tempo: tanggal + jam
- Estimasi dan waktu aktual
- Prioritas
- Status
  - Belum
  - Dikerjakan
  - Menunggu (brand, produk, editor)
  - Selesai
  - Batal
- Checklist
- Lampiran dan link
- Berulang
- Brand, platform, tag kampanye
- Penanggung jawab (fase tim)
- Catatan

## 7. Otomasi

- Jadwal mundur dari tanggal posting
- Tanggal posting digeser → semua tugas ikut geser
- Checklist beres → pindah tahap otomatis
- Tugas berulang
- Saran jam posting dari data
- Peringatan beban kerja berlebih
- Postingan hasil impor dicocokkan ke konten Terbit
- Pengingat evaluasi otomatis

## 8. AI

- Hook dan naskah
- Shot list dari naskah
- Caption dan hashtag
- Pecah satu ide jadi seri
- Repurpose ke platform lain
- Brief brand → checklist
- Ingatkan pola yang berhasil

## 9. Pengingat

- Ringkasan pagi
- Jam posting
- H-1 deadline endorse
- Tugas terlambat
- Evaluasi 24 jam
- Saluran
  - Push (PWA)
  - Email
  - Telegram
  - WhatsApp (nanti)
- Jam tenang dan hari libur

## 10. UX di HP

- Tombol (+) tambah tugas cepat
- Geser kanan selesai, kiri tunda
- Tombol besar, bisa satu tangan
- Tetap jalan offline, sinkron nanti
- Bagikan dari TikTok / IG ke referensi
- Layar tetap menyala di mode syuting

## 11. Kondisi khusus

- Pertama kali: template "7 hari pertama"
- Banyak terlambat: "Jadwal ulang semua"
- Konten batal → kembali ke Bank ide
- Produk endorse belum datang → Menunggu
- Multi brand: filter per brand
- Arsip, bukan hapus
- Konten evergreen untuk posting ulang
- Zona waktu

## 12. Kesehatan dan batas

- Kapasitas per minggu
- Hari libur
- Peringatan terlalu banyak tugas
- Rekam batch untuk hemat energi

## 13. Aturan dan etika

- Label iklan / kolaborasi berbayar
- Hak cipta musik
- Hak pakai konten oleh brand
- Izin talent dan lokasi
- Privasi data kolaborator

## 14. Ukuran keberhasilan

- % terbit tepat waktu
- Streak posting
- Lama ide → terbit
- Tahap yang paling sering macet
- Estimasi vs waktu aktual
- Tugas selesai per minggu

## 15. Hubungan dengan menu lain

- Ide → jadi konten + tugas
- Impor → cocokkan postingan
- Ringkasan → tugas hari ini
- Cuan → endorse, invoice, komisi
- Laporan → konsistensi dan kecepatan produksi

## 16. Gratis vs Pro

- Gratis
  - Tugas, checklist, kalender
  - 3 template
  - Mode simpel
- Pro
  - AI naskah, hook, shot list
  - Template tanpa batas
  - Jadwal mundur otomatis
  - Mode syuting + teleprompter
  - Alur endorse lengkap
  - Pengingat Telegram / WhatsApp
